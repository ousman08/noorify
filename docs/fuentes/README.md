# Fuentes del curso

Esta carpeta contiene los textos base que se pueden utilizar para redactar las lecciones de Asas.

## Qué se puede añadir

- Archivos Markdown (`.md`) o texto plano (`.txt`).
- Obras, extractos o materiales cuya licencia permita el uso previsto.
- Referencias bibliográficas exactas: autor, título, edición, volumen, página, capítulo o identificador verificable, según corresponda.

## Reglas

1. Comprueba la licencia y los permisos antes de incorporar cualquier texto.
2. La IA solo puede redactar a partir de los documentos incluidos aquí y de las referencias exactas que estos documenten.
3. No se debe completar información religiosa de memoria ni inventar aleyas, hadices, textos árabes o atribuciones.
4. Cada lección debe indicar sus fuentes y las dudas que una persona revisora debe comprobar.
5. Todo contenido generado empieza con estado `draft`. Solo una persona con conocimiento puede aprobarlo y cambiarlo a `reviewed`.

Si esta carpeta está vacía, el contenido de las lecciones debe permanecer como marcador de posición: `TODO: contenido pendiente de revisión`.
